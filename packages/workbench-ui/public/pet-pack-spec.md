# 桌宠动作包规范（Pet Pack Spec v1）

动作包是一个 zip 压缩包，用来给桌宠的**动作**提供自定义**动画**。
「动作」（语义）由应用状态机定义且固定不变；「动画」（素材）完全由你决定——
这实现了动画与动作的解绑：你只负责按本规范提供素材，应用负责在合适的时机播放。

## 1. zip 结构

```
my-pack.zip
├── pack.json                 # 必须，位于 zip 根目录
├── idle_breath/              # 动作目录（按需提供，可缺省）
│   ├── idle_breath_00.png
│   ├── idle_breath_01.png
│   └── ...
└── wave/
    ├── wave_00.png
    └── ...
```

- 帧文件命名严格为 `<动作>/<动作>_NN.png`，`NN` 从 `00` 起两位补零、连续无跳号；
- 只提供部分动作是可以的：**未提供的动作自动回落内置动画**；
- 除 `pack.json` 与声明的帧图外，不要放其它文件（多余文件会导致导入失败）。

## 2. pack.json

```json
{
  "schema": 1,
  "id": "my-pet",
  "name": "我的宠物",
  "author": "你的名字",
  "version": "1.0.0",
  "states": {
    "idle_breath": { "frames": 8, "fps": 6, "loop": true },
    "wave":        { "frames": 6, "fps": 6, "loop": false }
  }
}
```

| 字段 | 约束 |
| --- | --- |
| `schema` | 固定 `1` |
| `id` | `[a-z0-9_-]{1,32}`，全局唯一（重复 id 会被拒绝，需先删旧包） |
| `name` | 非空字符串，列表展示名 |
| `author` / `version` | `author` 可选；`version` 必填非空 |
| `states` | 非空对象，key 必须是下表动作 key 之一 |
| `states.*.frames` | `1..48`，**必须等于实际帧文件数** |
| `states.*.fps` | `1..30` |
| `states.*.loop` | `true` 循环播放 / `false` 播完驻留末帧 |

## 3. 动作 key 全集（10 个）

| key | 触发时机 | 建议 |
| --- | --- | --- |
| `idle_breath` | 待机（无会话） | 循环，安静的呼吸/站立 |
| `working` | 会话有输出 | 循环，忙碌感（打字等） |
| `eating` | 工作中 30s 无输出 | 循环 |
| `sleep` | 空闲约 5 分钟 / 断线 | 循环，睡眠感 |
| `need_input` | 等待用户确认（指纹等） | 循环，提示感 |
| `drag` | 被用户拖拽 | 循环，扑腾/挣扎 |
| `ready` | 唤醒登场 | 不循环，亮相 |
| `wave` | 悬停 / 被戳 | 不循环，打招呼 |
| `idle_blink` | 待机中随机眨眼 | 不循环，约 3 帧 |
| `angry` | 报错/失败 | 不循环，生气 |

动作的**节奏**（何时切换、停留多久）由应用状态机控制，与你素材的长度无关；
非循环动作由应用在固定时长后回落基础状态，末帧驻留。因此非循环动作不必做得很长。

## 4. 美术要求

- PNG 格式、**带透明通道**（背景透明，不要白底）；
- 宽/高 ≤ 2048 像素；建议 512×512 以内；
- **同状态所有帧使用同一取景框**（角色在画布中的位置、大小一致），否则播放会抖动；
- 脚底（或底边中点）建议对齐画布同一锚点，动作间切换不跳位；
- 不同动作的画布尺寸可以不同，但底边锚点建议保持一致。

## 5. 导入校验（不满足即拒绝）

- zip ≤ 30MB，解压后总大小 ≤ 80MB，条目数 ≤ 600；
- 路径安全：拒绝 `..`、绝对路径、盘符、符号链接；
- 每张帧图校验 PNG 文件头且尺寸 ≤ 2048；
- `frames` 与实际文件数严格一致、文件名严格匹配、无多余文件；
- 未知动作 key、非法 id、重复 id 拒绝。

## 6. 使用方式

桌宠右键菜单 →「动作包管理」→「导入动作包（zip）」→ 选中你的 zip。
导入后点「启用」立即生效；可随时删除或「恢复内置」。
